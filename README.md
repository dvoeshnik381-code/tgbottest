# Локальный Telegram бот

Персональный Telegram-помощник, который работает на вашем компьютере без сторонних npm-пакетов.

## Что умеет

Все основные действия доступны через постоянные кнопки снизу:

- Заметки
- Дела
- Покупки
- Напоминания
- Погода
- Валюта
- Бюджет
- Дневник
- Привычки
- Ссылки
- Информация о ПК
- Кубик и орел-решка

## Форматы ввода

Напоминания:

```text
через 30 минут проверить чай
через 2 часа созвон
завтра 10:00 оплатить интернет
```

Бюджет:

```text
250 кофе
5000 аванс
```

Ссылки:

```text
https://example.com полезная статья
```

Калькулятор все еще работает командой:

```text
/calc 2 + 2 * 5
```

## Запуск

```powershell
node src/bot.js
```

Остановить бота можно через `Ctrl+C`.

## Данные

Все личные данные сохраняются локально в `data/bot-data.json` рядом с ботом.

## Важно

Не публикуйте `.env` и токен бота. Любой, у кого есть токен, может управлять вашим ботом.
