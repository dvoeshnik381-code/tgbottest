# Алиса Мини, ИИ и выключение Windows 10 на домашнем ПК

Теперь тот же Telegram-бот может одновременно обрабатывать вопросы Алисы. Отдельный VPS не нужен: приложение запускается на Windows 10, хранит память и выполняет подтверждённое выключение. Во время сна, выключения ПК или отсутствия интернета этот помощник недоступен. Обычная Алиса вне навыка продолжает работать.

## Запуск и Telegram

1. Установите Node.js версии 18+ и обновите исходники проекта. Зависимостей npm нет.
2. Сохраните существующий `.env` и `data/bot-data.json`; добавьте новые параметры из `.env.example` в свой `.env`. Не заменяйте токен вашего первого бота новым: это тот же бот.
3. В `OWNER_CHAT_ID` запишите свой числовой ID личного Telegram-чата. Отправьте боту сообщение: его терминал показывает `Message from chat ...`. Не используйте групповой ID. Новые ИИ-функции и выключение доступны только когда совпадают ID чата, ID отправителя и тип личного чата.
4. Добавьте `OPENAI_API_KEY`. В `OPENAI_MODEL` по умолчанию стоит `gpt-6-luna`; можно указать другую доступную вашему API-проекту модель. Для диалога запросы OpenAI API платные. Бесплатный тестовый запрос, если доступен аккаунту, не гарантирует бесплатного постоянного использования.
5. Выполните в папке проекта:

   ```powershell
   node src/bot.js
   ```

6. Откройте «🧠 ИИ-помощник» или отправьте `/ask вопрос`. Ответ придёт автоматически. Во время подготовки доступны обычные кнопки. «Главное меню» возвращает обычные функции.

Не запускайте два процесса `getUpdates` с одним токеном. Если старый бот уже работает на хостинге, остановите его перед локальным запуском. Исходники в GitHub сами по себе не запускают приложение на вашем ПК.

## Память

- `/remember сведения` или «➕ Запомнить» — сохранить выбранные сведения.
- `/memory` — прочитать память.
- `/forget_memory` — очистить память ИИ и историю разговора, сохранив заметки, дела и остальные разделы.
- `/answer` — повторить последний результат.

Алиса и владелец Telegram используют одну память. Она хранится в существующем `data/bot-data.json`, в поле `assistant` пользователя. Для запроса используются последние 12 сообщений; на диске хранятся последние 40 и до 50 явно сохранённых сведений. Это отдельная память проекта, без импорта чатов ChatGPT. После перезапуска последний успешный ответ и память сохраняются, текущий запрос нужно повторить.

## Выключение компьютера

В `.env`:

```dotenv
PC_CONTROL_ENABLED=true
PC_DRY_RUN=true
```

Перезапустите бота. Отправьте `/shutdown`, затем `/confirm_shutdown` или нажмите кнопку подтверждения. Срок подтверждения — 60 секунд. В тестовом режиме компьютер останется включённым.

Когда убедитесь, что управление работает только для вашего личного чата, измените `PC_DRY_RUN=false` и перезапустите. После подтверждения начинается 30-секундный отсчёт. Отмена: `/cancel_shutdown`, кнопка отмены, голосовая команда «отмени выключение» в навыке или остановка процесса до конца отсчёта. `/pc_status` показывает состояние.

Выключение запускается только на Windows и только явно разрешённым кодом. Модель не исполняет shell-команды. Отсчёт идёт внутри приложения, затем вызывается штатный `shutdown.exe /s /t 0` без `/f`; несохранённые документы могут остановить выключение. Подтверждение связано с источником: Telegram не может подтвердить запрос из сессии Алисы. После запуска самого системного выключения отмена не гарантируется. Проект не включает включение выключенного ПК.

## Алиса на том же ПК

В `.env` добавьте:

```dotenv
ALICE_ENABLED=true
ALICE_PORT=8080
ALICE_WEBHOOK_TOKEN=случайный_секрет_не_короче_32_символов
ALICE_PAIRING_MODE=true
ALICE_USER_ID=
ALICE_APPLICATION_ID=
```

Секрет можно создать локально:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

1. Перезапустите бота. Он слушает `127.0.0.1:8080`; входящие порты роутера открывать не требуется.
2. Установите [cloudflared](https://developers.cloudflare.com/tunnel/downloads/) и для первого теста запустите отдельным окном:

   ```powershell
   cloudflared tunnel --url http://localhost:8080
   ```

   Получите временный HTTPS-адрес `https://....trycloudflare.com`. Это туннель к процессу на вашем ПК, а не отдельный сервер для бота. Не включайте интерактивную email-авторизацию туннеля: серверы Яндекса не смогут пройти её.
3. Создайте приватный навык в [Яндекс Диалогах](https://dialogs.yandex.ru/developer/). Активационное имя, например «Мой помощник». Укажите Webhook URL `https://....trycloudflare.com/alice/ВАШ_СЕКРЕТ`. Выберите голосовую поверхность/Станцию и выполните публикацию приватного навыка с автоматической модерацией.
4. Запустите навык голосом на своей Алисе Мини. В терминале бота появится `ALICE_PAIRING` с двумя идентификаторами. Скопируйте их в `ALICE_USER_ID` и `ALICE_APPLICATION_ID`, поставьте `ALICE_PAIRING_MODE=false` и перезапустите бота. До этого команды и доступ к памяти отключены. ID текстового тестирования может отличаться от ID Станции.
5. Задайте вопрос. В течение лимита 4,5 секунды навык скажет «готовлю ответ»; через несколько секунд скажите «готово». «Отправь ответ в Телеграм» запускает отправку полного ответа в тот же первый бот. Отправку проверяйте в чате — голосовой ответ подтверждает запуск отправки, а не факт доставки.
6. «Запомни ...», «Что ты обо мне помнишь», «Выключи компьютер», «Подтверждаю», «Отмени выключение» используют те же память и управление ПК.

Временный туннель предназначен для тестов, без гарантии доступности. Его адрес меняется при новом запуске и перестаёт работать при остановке. Для постоянного пользования настройте именованный Cloudflare Tunnel со стабильным HTTPS-адресом и обновите webhook. Туннель и приложение должны работать одновременно; не публикуйте полный webhook URL с секретом в логах/скриншотах.

Проверка владельца навыка относится к аккаунту и устройству, а не к голосу человека. Любой рядом с колонкой в активном навыке может произнести подтверждение. Сам помощник после выключения ПК работать не будет до следующего включения. Для автозапуска настройте Планировщик задач Windows на запуск `node.exe src/bot.js` из папки проекта при входе пользователя; приложение и туннель автоматически пока не устанавливаются.

## Проверка

```powershell
npm test
```

Тесты выполняют локальные HTTP-запросы, имитируют OpenAI и выключение: реальные внешние запросы и выключение ПК не выполняются. Запуск на вашей Windows 10, реальная колонка, Telegram и ключ OpenAI требуют отдельной проверки после установки.
